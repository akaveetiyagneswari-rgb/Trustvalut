Trustvalut – Secure Document Management System
About

Trustvalut is a web-based secure document management application developed using Python Flask and SQLite.

Features
User registration and login
Password hashing
Admin and user roles
Secure document uploads
Document download with ownership verification
Audit history
Server-side access control
Technologies
Python
Flask
SQLite
HTML
CSS
GitHub
Run locally
Install dependencies:

pip install -r requirements.txt

Start the application:

python app.py

Open http://127.0.0.1:5000 in your browser.
